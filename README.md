# Karman — демо-криптокошелёк для Telegram

Тренажёр в духе Tonkeeper: настоящие котировки, графики, демо-счёт для торговли и автотрейдер,
который работает круглосуточно на сервере. Три части в одном процессе (`bot.py`):

- **Бот** — цены, графики картинкой, сделки прямо в чате, уведомления о сделках автотрейдера.
- **Приложение** (`app/index.html`) — Telegram Mini App с полным интерфейсом: портфель, обмен,
  переводы, стейкинг, автотрейдер с бэктестом. Раздаёт его тот же процесс.
- **API** (`api.py`) — приложение ничего не хранит само, всё в базе; счёт у бота и приложения общий.

**Ничего настоящего здесь не покупается.** Нет блокчейна, кошельков и переводов.
Цены берутся с CoinGecko, деньги — виртуальные.

## Что умеет

| Раздел | Что внутри |
|---|---|
| 👛 Кошелёк | Общий баланс, наличные, монеты с прибылью по каждой, стейкинг, настроение портфеля |
| 📈 Рынок | TON, BTC, ETH, SOL, BNB, DOGE, NOT — цена и изменение за 24ч |
| Карточка монеты | График (24ч / 7д / 30д / год), позиция, кнопки «Купить» / «Продать» |
| Торговля | Быстрые суммы, проценты от счёта, ввод числа, подтверждение перед сделкой |
| 🧾 История | Все операции: сделки, обмены, переводы, кран, стейкинг; сделки бота помечены 🤖 |
| ⚙️ Настройки | Валюта показа ($ / ₽ / €), период графика по умолчанию, сброс демо-счёта |

Только в приложении: **Обмен** монета↔монета по курсу, **Отправить** на адрес/@username,
**Получить** (демо-адрес с QR и кран +$1000), **Стейкинг TON** под 4,5% годовых, достижения.

**🤖 Автотрейдер** (вкладка «Бот») торгует на демо-счёте сам по одной из стратегий:
«Откат» (покупка при просадке ниже средней за сутки, выход по тейк-профиту/стоп-лоссу),
«Тренд» (пересечение средних 6ч/24ч), «Сетка» (партии на каждом шаге падения). Настраиваются
бюджет, размер сделки, параметры и набор монет. Кнопка «Проверить за 30 дней» прогоняет
стратегию по реальной истории и сравнивает с простым удержанием. **Бот работает на сервере
круглосуточно**, приложение можно закрыть; о каждой сделке приходит сообщение в чат.

Новый пользователь получает $10 000 (`START_CASH`). Сделки исполняются по текущей цене,
без комиссии. Прибыль считается от средней цены покупки.

## Запуск на компьютере

**1. Свой бот.** Напиши [@BotFather](https://t.me/BotFather), команда `/newbot`. Получишь
токен вида `1234567890:AAE...`. Это должен быть **отдельный** бот — один токен не могут
слушать два процесса.

**2. Настройки.**

```powershell
Copy-Item .env.example .env
notepad .env        # вставить токен в BOT_TOKEN
```

**3. Зависимости** (один раз, если папки `.venv` ещё нет):

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

**4. Старт:** двойной клик по `start.bat` или

```powershell
.\.venv\Scripts\python.exe bot.py
```

Бот отвечает в Telegram, приложение открывается в браузере по `http://localhost:8080`
(чтобы видеть в нём свой счёт из браузера, задай в `.env` `DEV_USER_ID=<твой Telegram id>`).
Кнопки Mini App в чате появятся, когда у приложения будет HTTPS-адрес: либо облако (ниже),
либо туннель с компьютера — `start_app.bat` (нужен `tools\cloudflared.exe`, команда для
скачивания печатается при запуске). Адрес туннеля меняется при каждом запуске.

## Развёртывание: чтобы работало без компьютера

Нужно два бесплатных сервиса: **Render** (процесс) и **Supabase** (база Postgres — у Render на
бесплатном тарифе диск не сохраняется, SQLite там пропадёт при первом же перезапуске).
Карта не нужна ни там, ни там.

### 1. Код на GitHub

Репозиторий должен содержать **всю папку `wallet`** (bot.py, api.py, app/, requirements.txt, …),
без `.env`, `.venv` и `karman.db` (см. `.gitignore`). Через веб-интерфейс: **Add file → Upload
files**, перетащить содержимое папки. Старую страницу на GitHub Pages можно выключить — приложение
теперь раздаёт сам сервер.

### 2. База: Supabase

1. [supabase.com](https://supabase.com) → New project. Регион — **eu-central-1 (Frankfurt)**,
   тот же, что у сервиса на Render, иначе каждый запрос к базе будет идти через океан.
   Пароль базы сохрани.
2. На странице проекта кнопка **Connect** → вкладка **Session pooler** → скопировать URI вида
   `postgresql://postgres.xxxx:[YOUR-PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:5432/postgres`,
   подставить пароль. Именно **pooler**, не Direct: прямое подключение у Supabase только по IPv6,
   а у Render его нет.

Таблицы создаст сам бот при первом запуске.

### 3. Процесс: Render

1. [render.com](https://render.com) → **New → Blueprint** → выбрать репозиторий: Render прочитает
   `render.yaml` и спросит секреты:
   - `BOT_TOKEN` — токен бота;
   - `DATABASE_URL` — строка из Supabase;
   - `WEBAPP_URL` — адрес сервиса, Render показывает его сразу: `https://<имя>.onrender.com/`
     (со слэшем на конце);
   - `KEEPALIVE_URL` — тот же адрес + `health`: `https://<имя>.onrender.com/health`.
2. Дождаться деплоя (3–5 минут). В логах должно быть `База: Postgres` и `запущен как @…`.
3. В боте отправить `/start` — появится кнопка приложения.

Если создавать не через Blueprint, а руками: Web Service, runtime Python, build
`pip install -r requirements.txt`, start `python bot.py`, те же переменные окружения плюс
`PYTHON_VERSION=3.12.7`. Или Docker — `Dockerfile` в комплекте, подойдёт любому хостингу.

### 4. Чтобы не засыпал

Бесплатный Render останавливает сервис через 15 минут без входящих запросов — вместе с ботом
и автотрейдером, а просыпается за 30–60 секунд после первого запроса. Два рубежа:

- `KEEPALIVE_URL` — процесс сам дёргает свой `/health` раз в 10 минут;
- внешний пинг на всякий случай: [uptimerobot.com](https://uptimerobot.com) (бесплатно) →
  New monitor → HTTP(s), адрес `https://<имя>.onrender.com/health`, интервал 5 минут.

Бесплатный лимит Render — 750 часов в месяц на аккаунт: одного сервиса круглосуточно хватает,
двух — уже нет.

### Обновить после правок

Загрузить изменённые файлы в репозиторий — Render пересоберёт сервис сам (`autoDeploy`).
Telegram может показывать старую версию приложения из кэша: закрой и открой Mini App заново.

## Тесты

```powershell
.\.venv\Scripts\python.exe -m unittest -v
```

Всегда на SQLite и без сети: цены подменены, API гоняется через aiohttp-клиент в памяти.

## Если что-то не работает

**`BOT_TOKEN не задан`** — нет `.env` или пустой `BOT_TOKEN` (на хостинге — переменная окружения).

**«Биржа не отвечает»** — CoinGecko недоступен или отдал лимит (429). Сервер показывает
последние известные цены и сам обновит их, когда API оживёт. Бэктест и графики за 30 дней
на новом сервере могут не открыться с первого раза — лимит общий на IP, подожди минуту.

**`Conflict: terminated by other getUpdates`** — этот же токен запущен дважды (например,
на компьютере и в облаке). Останови один.

**Приложение пишет «Открой приложение из Telegram»** — страница открыта без подписи Telegram
и без токена из ссылки «Открыть в браузере». Открой через кнопку в чате.

**`Postgres: соединение потеряно`** в логах — пул Supabase закрыл простаивающее соединение;
следующий запрос переподключится сам.
